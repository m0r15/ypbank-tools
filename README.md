# ypbank-tools

Один Cargo package: библиотека для транзакций и два CLI-приложения. Чтение и
запись библиотеки обобщены по `Read` и `Write`; CSV и text используют общий
модуль обработки разделённых строк.

## Структура

```text
src/
+-- lib.rs
+-- main.rs              # converter
+-- model.rs
+-- error.rs
+-- format.rs
+-- delimited.rs         # общее чтение/запись CSV и text
+-- csv_format.rs        # настройки CSV
+-- text_format.rs       # настройки text
+-- bin_format.rs
+-- compare.rs
+-- cli_args.rs          # общие CLI-помощники
+-- bin/comparer.rs
```

## Форматы

CSV начинается заголовком `date,category,kind,amount`, затем содержит строки
с четырьмя полями. Text использует те же поля через `;`, без заголовка.
Тип операции — `income` или `expense`, сумма — целое `i64`, дата — `YYYY-MM-DD`.
CSV quoting не поддерживается. Категория в CSV/text не может содержать
разделитель или перевод строки; пробелы по краям обрезаются при чтении.
Пустые строки при чтении игнорируются.

### Бинарный формат

Числа представлены в little-endian, без padding. Заголовок — 9 байт:

| Поле | Размер |
|---|---:|
| Magic `YPBN` | 4 байта |
| Версия (`1`) | `u8` |
| Количество записей | `u32` |

Запись состоит из года `u16`, месяца `u8`, дня `u8`, типа `u8` (`0` income,
`1` expense), суммы `i64`, длины категории `u32` и UTF-8-байтов категории.
Максимальная длина категории — 1 МиБ, максимальное количество записей —
1 000 000. После объявленного числа записей лишние байты запрещены.

## Запуск

```bash
cargo run --bin converter -- --from csv --to text --input data.csv
cat data.csv | cargo run --bin converter -- --from csv --to bin > data.bin

# два способа задать файлы: позиционными путями (первый — левый, второй — правый)…
cargo run --bin comparer -- data.csv data.txt
# …или флагами --left/--right
cargo run --bin comparer -- --left data.csv --right data.bin
```

Converter читает файл через `--input` или stdin, результат пишет в stdout.
Аргументы `--from` и `--to` обязательны.

Comparer принимает два файла: либо два позиционных пути (первый — левый,
второй — правый), либо флаги `--left` и `--right`. Формат каждого файла можно
задать явно флагами `--left-format`/`--right-format`; если флаг не задан,
формат определяется по расширению: `txt`/`text` → text, `csv` → csv,
`bin` → bin, а файл без расширения считается бинарным.

Comparer сравнивает распарсенные транзакции: порядок и количество важны,
выводится первое различие. Код возврата: `0` — успех/совпадение, `1` —
различие comparer, `2` — ошибка аргументов, ввода-вывода или формата.
